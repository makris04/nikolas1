# Y-Balance Calibration & Learning Effect App

This Streamlit app evaluates:
- calibration bias
- composite Y-Balance scores
- percent change from Trial 1 to Trial 4
- paired t-test p-value

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## App features
- Scenario selector: Scenario A / Scenario B
- Tab 1: Data & Calibration Bias
- Tab 2: Learning Effect
- Tab 3: Diagnostic Alerts
